# unity-prefab-batch-renamer

A Unity editor window that renames selected Prefab assets in bulk using a configurable prefix and suffix.

## Stack

Primary language: **C#**

## Project structure

- `Assets/Editor/PrefabBatchRenamer.cs` — Bulk rename Prefab assets in the Project window with prefix/suffix options.
- `Assets/Editor/PrefabBatchRenamer.cs.meta` — meta file for editor script

## Usage

Review the source files and install any dependencies referenced by the project before running it.
